2 Demo Flow PAGE-BY-PAGE

🏠 Home Page se start karo

  • Hero section dikhao.
Yahan customer turant pickup city, delivery city, truck type select karke instant freight estimate le sakta hai.
  • Neeche scroll karo → Services (FTL, PTL, Container, Express…), animated stats (10,000+ trucks), testimonials, FAQ.
Ye sab ek professional corporate website jaisa feel deta hai.

🔗 Live Brokerage Flow SABSE STRONG POINT

  • Transporters page → filters use karke (state, city, fleet size) ek transporter dhoondo.
  • View Profile → uski rating, documents, reviews, routes dikhao.
  • Request a Quote dabao →
Dekhiye sir, form automatically pre-fill ho gaya — transporter ka naam, city sab. Customer ko dobara type nahi karna padta.
  • Submit karo → upar notification bell baj gayi + niche table me enquiry aa gayi.
Ye real-time lag raha hai.

🧮 Fare Calculator

Koi route + truck daalo → full breakdown dikhao (base fare, fuel, toll, driver, GST).

Transparent pricing — koi hidden charge nahi.
